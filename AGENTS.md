# Project rules for AI assistants

This file is the central place for project-wide rules as we prepare responses to reviewer comments. Add further project rules here as they are agreed.

## Data and R restrictions

- **Do not inspect any raw data.** Do not open, read, preview, search within, or otherwise access raw data contents, including through tools or delegated agents.
- **Do not execute any R code.** This includes R scripts, R commands, R-backed notebooks, R Markdown or Quarto documents containing R, and tests or workflows that execute R, directly or indirectly.
- These restrictions apply to all tools and delegated agents. Do not bypass them through another language or tool.
- If a task requires raw-data inspection or R execution, ask the user to perform that step and provide an appropriate non-raw-data summary or output.
